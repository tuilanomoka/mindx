MindX là nền tảng học tập tư duy sử dụng AI với Prompt tối ưu làm lõi chính.
1. Chế Độ Học Tập (Learning Mode):
+	Mục tiêu: Nắm vững kiến thức.
+	Tính năng: Giải bài toán và liệt kê đầy đủ các bước giải chi tiết cùng kết quả. Hỗ trợ học tập không giới hạn.
2. Chế Độ Rèn Luyện (Training Mode):
+	Mục tiêu: Rèn luyện khả năng giải độc lập.
+	Tính năng: Tương tự Chế độ Học tập, nhưng che các bước giải và kết quả.
+	Tính điểm:
+	Nhập kết quả chính xác = Điểm cao nhất.
+	Bỏ che bước giải = Mất một phần điểm.
+	Xem luôn kết quả = 0 điểm.
3. Xếp Hạng & Cửa Hàng (Ranking & Shop):
+	Xếp Hạng: Liệt kê top những người có điểm cao nhất từ chế độ Rèn luyện.
+	Cửa Hàng: Tích lũy điểm để mua các vật phẩm trang trí (khung avatar, v.v.).
